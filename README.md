# ScamShield AI

AI-powered scam risk detection for screenshots and suspicious digital content.

## Goal

Help users identify scam risks before they click suspicious links, provide OTP codes, transfer money, or disclose sensitive information.

## Buildmode MVP

```text
Screenshot / Image
→ Multimodal AI
→ Scam Risk Analysis
→ Risk + Reasons + Recommended Actions
```

## MVP Input

- Screenshot
- Image

## MVP Output

- Risk Score
- Risk Level
- Category
- Signals
- Recommendations
