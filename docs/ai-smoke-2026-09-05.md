## 發現與修復

第 4 個 signal reason 尾端混入 `}],`。整體 response 是有效 JSON，該片段位於合法字串內，所以原有 public text schema 未拒絕。此結果不可直接當成 UI 品質通過。

`lib/server/ai/normalize.ts` 已增加 Provider 文字結構尾碼檢查；summary、signal reason 或 recommendation 若以 JSON delimiter debris 結尾，統一回 `analysis_failed`，不嘗試靜默修補。`tests/unit/pipeline.test.ts` 已加入三種欄位的回歸案例。
